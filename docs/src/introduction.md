# Stock Analyzer Skill

> 装进 Claude Code，每天 10 分钟做完 A 股持仓体检与复盘。

12 个 skill（8 核心 + 4 变体）。**日常只用两条命令**：`/portfolio health` 体检持仓、`/market quick` 复盘大盘；选股、回测、深度研究是低频进阶工具。本包不荐股、不承诺收益，卖的是可复核的分析流水线——[定位说明](../positioning.md)。

> ✅ **适合你吗？** 已在用 AI 编码代理、每天看盘 5–10 分钟、愿意复核数据来源 → 直接看下面的「快速开始」。❌ 想要点开即用的荐股 App → 这里不适合你。

## 核心能力

- **五层分析框架**：基本面 · 估值 · 技术面 · 板块 · 风险收益比——一句话：从"公司好不好、贵不贵、走势强不强、板块配不配合、风险收益划不划算"五个角度各打一分
- **8 人活跃专家圆桌（含 16 份专家档案）**：8 位不同流派的"虚拟投资人"各自打分投票，把模糊判断变成可复核的多空对照；8 份 legacy 档案是历史合体素材，不参与投票
- **37 个 fetcher 类故障转移**：腾讯 · 东财 · 新浪 · 雪球 · 同花顺 · AkShare · efinance，单源挂掉自动切下家
- **零配置数据**：内置预置默认股票池，无 token 即可启动；但需终端环境能跑 `install.sh`，不是点开即用的 App

## 快速开始

```bash
# 0. 初始化股票池（仅首次；离线用 default）
/screener init

# 1. 每天真正会用的两条命令
/portfolio health
/market quick

# 2. 想看懂某只股票为什么涨跌
/stock sh600519 quick
```

> ⚠️ 所有输出**仅供参考，不构成投资建议**。看不懂 PE / ROE / 缠论？用 `/learn` 随时提问，或看 [methodology.md](../../methodology.md) 附录。
