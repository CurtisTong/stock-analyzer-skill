# /research

**财务建模 / 排雷 / DCF / 全维度研究报告。** 单笔仓位重、需要决策依据存档时用。

## 什么时候用

| 你的问题 | 直接输入 |
| --- | --- |
| 财务质量 / 排雷 | `/research financial 分析贵州茅台财务质量` |
| 完整投资研究报告 | `/research report 研究贵州茅台，给一份完整投资报告` |

## 输出长什么样

项目 demo 的合成演示输出（结构稳定，数值随行情变化）：

```text
🎯 财务健康，无重大风险
ROE: 31.2%（连续 5 年 > 25%）
毛利率: 91.5%（行业最高）
资产负债率: 28.5%（低负债）
📊 数据时间戳: 2026-06-15 14:30 | 数据源: 东方财富财务
```

**术语**：DCF（现金流折现）= 把未来能赚的钱折算成今天值多少；排雷 = 查商誉 / 质押 / 应收等财务风险点；ROE = 用股东的钱赚钱的效率。详见 [methodology.md](../../methodology.md)。

> ⚠️ 报告里的"评级 / 目标价 / 止损位"均为演示，**仅供参考，不构成投资建议**。
