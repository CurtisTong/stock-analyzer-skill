# /stock-help

**帮助索引：5 类场景入口 + 全部 skill 一句话表。** 不知道该用啥时输入它——这是"我现在该用啥"的标准答案。

## 直接复制

```bash
/stock-help
```

你会看到：

```text
你现在最关心什么？
🔍 我想找机会（选股）
📊 我想看大盘（复盘）
💼 我想看持仓（管理）
🎤 我想深度研究（单股）
📈 我想看板块（行业）
```

## 口语 → 命令速查

| 你心里想说的 | 直接输入 |
| --- | --- |
| "看看我的持仓" | `/portfolio health` |
| "帮我调仓 / 给点调仓建议" | `/portfolio rebalance` |
| "今天大盘怎么样" | `/market quick` |
| "推荐几只股票 / 帮我选股" | `/screener` |
| "这只股票能买吗" | `/stock sh600519 full` |
