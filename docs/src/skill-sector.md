# /sector

**板块全景 / 核心标的对比 / 板块内筛选。** 想知道"这个行业现在冷热如何、谁最强"时用。

## 什么时候用

| 你的问题 | 直接输入 |
| --- | --- |
| 板块整体怎么样 | `/sector 白酒 overview` |
| 板块内谁最强 | `/sector 资源 compare` |
| 板块内筛股 / 指定个股深挖 | `/sector 医药 stock 恒瑞医药` |

## 输出长什么样

项目 demo 的合成演示输出（结构稳定，数值随行情变化）：

```text
🎯 白酒板块整体偏弱，资金净流出
核心标的:
贵州茅台  现价 1,652  +0.85%  PE 22.1  ROE 31.2%
五粮液    现价 158.5  -0.32%  PE 18.5  ROE 25.8%
📊 数据时间戳: 2026-06-15 14:30 | 数据源: 腾讯行情, 东方财富财务
```

> ⚠️ 板块资金流向与强弱判断**仅供参考，不构成投资建议**。
