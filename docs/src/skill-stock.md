# /stock

**单股五层分析 + 8 位活跃专家圆桌辩论。** 日常不用它；想看懂某只股票"为什么涨跌、值不值得深究"时用。

> ⚠️ 输出含评级与观察价位，**仅供参考，不构成投资建议**。

## 什么时候用

| 你的问题 | 直接输入 |
| --- | --- |
| 这只股票现在什么情况 | `/stock sh600519 quick` |
| 想要完整论证（五层） | `/stock sh600519 full` |
| 想听多空双方怎么吵 | `/stock sh600519 debate` |

## 输出长什么样

项目 demo 的合成演示输出（结构稳定，数值随行情变化）：

```text
🎯 🟢 贵州茅台（sh600519）现价 1392.05（+2.81%）｜综合评分 42.1（中性）｜谨慎回避
【基本面】ROE 24.5%（行业Top）│ 毛利率 91.5% │ 净利YoY -0%
【估值】PE 22.1 │ 近5年估值分位 23%
【技术面】MA 多头排列 │ MACD 0 │ RSI 70 │ KDJ超买区(J=98)
📊 数据时间戳: 2026-10-31T12:27 | 数据源: 行情[tencent], K线[sina], 财务[eastmoney]
📜 本输出为量化研判参考，不构成投资建议，据此操作风险自负
```

**术语**：PE（市盈率，粗略理解成"多少年回本"）、ROE（净资产收益率，用股东的钱赚钱的效率）、MACD / KDJ / RSI（从价格算出的技术指标）——见 [methodology.md](../../methodology.md)，或随时用 `/learn 什么是PE`。
