# /market

**大盘快评 / 完整复盘 / 盘中分时。** 两个日常入口之一：每天开盘前定情绪、收盘后做复盘。

## 什么时候用

| 你的问题 | 直接输入 |
| --- | --- |
| 今天大盘怎么样 | `/market quick` |
| 想要指数 + 板块 + 资金全景 | `/market full` |
| 盘中想看分时异动 | `/market intraday` |

## 输出长什么样

项目 demo 的合成演示输出（结构稳定，数值随行情变化）：

```text
📅 2026-06-11 收盘复盘
上证 3,142 (+0.32%)  深成 10,856 (+0.58%)  创业 2,234 (+1.12%)
【风格】成长 > 价值 │ 小盘 > 大盘 │ 进攻信号 🟢
【板块 Top3】AI 算力 +3.8% / 半导体 +2.4% / 新能源车 +1.9%
【主力资金】净流入 87 亿（连续 3 日）
🎯 策略：进攻型仓位可提升至 70%，重点关注算力/半导体补涨
📜 本输出为量化研判参考，不构成投资建议，据此操作风险自负
```

> ⚠️ 上面的"仓位可提升至 70%"是演示输出，**仅供参考，不构成投资建议**。
